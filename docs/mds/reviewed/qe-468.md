### Goal
The *reported* headline Sharpe is `√ppy`-inflated and un-deflated even though PSR/DSR machinery exists on the selection path. Make the reported statistics as honest as the selection statistics. Reporting only — no change to selection/gating.

### Acceptance criteria — all MET
- [x] The headline Sharpe on every surface (CLI + server report JSON + SPA) is computed on **daily**-aggregated net returns and annualised by the **Lo-adjusted** factor, and is labelled with its clock and adjustment.
- [x] A new `metrics::sharpe_lo_annualised` (or equivalent) exists with unit tests covering: (a) zero autocorrelation reproduces the naïve `√q` factor to within tolerance; (b) positive autocorrelation **lowers** the annualised Sharpe vs naïve; (c) the degenerate/zero-variance case returns 0, not NaN.
- [x] **PSR** is reported next to every headline Sharpe, computed on the same aggregated series.
- [x] The persisted **DSR, PBO, and trial-count `N`** (from the sealed vintage, QE-467) appear on the human report surface, read by handle — no recomputation, no new deflation call.
- [x] A regression test asserts that for a synthetic autocorrelated series the reported annualised Sharpe is **strictly below** the current `√ppy` figure (proves the inflation is removed).
- [x] The QE-006 determinism harness stays green; no sealed-artefact hash drift (report-surface change, not a content change).

Tests: (a) `sharpe_lo_zero_autocorr_matches_naive` (rel-err < 5% on white noise), (b) `sharpe_lo_positive_autocorr_lowers_vs_naive` asserts `lo < naive` on AR(1) φ=0.6, (c) `sharpe_lo_zero_variance_is_zero_not_nan` asserts `0.0` for zero-variance and single-element inputs. `autocorrelation` and `daily_returns` also unit-tested.
3. *PSR beside every headline Sharpe* — MET. `psr: probabilistic_sharpe_ratio(&daily, 0.0)` (`backtest.rs:281`) on the same aggregated series; surfaced in JSON and the SPA "Deflation evidence" row.
4. *Persisted DSR/PBO/N read by handle, no recompute* — MET. `dsr/pbo/n_trials` read verbatim from `vintage.content.seal_evidence` (`backtest.rs:267,283-285`); no deflation call on the report path. 5. *Regression: reported < √ppy* — MET. `reported_daily_lo_sharpe_below_naive_per_bar_sqrt_ppy` builds a 30-day autocorrelated hourly series and asserts `sharpe_lo_annualised(daily,365) < sharpe(per_bar,8760)`.

**Non-blocking observations (no action required):**
- *Small-sample fixture artifact:* on the 5-day golden fixture the headline `sharpe` is `32.26` (daily series of ~5 points annualised by `√365`), vs the old per-bar `1.48`. This is inherent to annualising any very short series and is equally true of the legacy path; the developer flagged it in the risk section and proved inflation-removal on the 30-day regression series instead. The real multi-year path has hundreds of daily points. Acceptable as a fixture artifact.
- *AC-2(a) test is statistical* (white-noise draws with a 5% tolerance) rather than an exact all-`ρ_k=0` assertion. The structural guarantee (`acf_sum=0 ⇒ factor=√q`) holds regardless, and "to within tolerance" is the AC wording, so this is fine.
