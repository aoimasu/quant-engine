### Implementation summary
- New `crates/validation/src/cpcv.rs` (sibling to `pbo_cscv`): reuses `pbo.rs`'s balanced-partition `combinations` enumeration verbatim; emits leak-free held-out paths; reduces to a distribution (median/IQR/5th–95th pct + fraction ≥ DSR floor); `CpcvGate` decides on the **lower 5th percentile** of held-out DSR, failing closed on under-power (`n_paths < min_paths`).
- **`qe-validation` cannot depend on `qe-wfo`** (would cycle: wfo→validation), so the purge+embargo arithmetic is **mirrored**, with a cross-crate test in `qe-wfo` (`validation_cpcv_purge_matches_purged_kfold`) binding it to `PurgedKFold::folds` block-for-block.
- Summary persisted via additive `SealEvidence.cpcv: Option<CpcvSummary>` (`#[serde(default, skip_serializing_if = "Option::is_none")]`); each path deflated against the same trial basis the G1 DSR uses. PBO untouched. `SealEvidence` dropped `Copy` (now holds `Vec`s); sole ripple fixed at `crates/server/src/read.rs:323`.
- **Path-count formula:** `n_splits = C(S, S/2)`; paths `φ(S) = C(S−1, S/2−1)` (S≥4 ⇒ φ≥2); seal uses `S=6` → 20 held-out configs.
- **B1 fix (live wiring, fail-closed):** after `evaluate_g1`, `train.rs` builds the CPCV distribution once (`.ok()`), feeds both gate and seal; `cpcv_gate_pass = cpcv_dist.as_ref().is_some_and(|d| CpcvGate::default().passes(d))` (→ `false` on absent/degenerate = fail-closed); appends auditable `CriterionResult "cpcv_oos_distribution_clears_floor"`; conjoins `g1.promoted = g1.promoted && cpcv_gate_pass`. `cpcv = None` exactly when under-powered — never sealed-and-promoted on under-power.
- **Live integration test:** `cpcv_gate_is_wired_into_the_live_promotion_verdict_and_fails_closed` (`crates/cli/tests/train_job.rs`) — powered run binds `promoted == point_estimate_pass && cpcv.passed` (20 sealed paths); under-powered run (`holdout=115`) asserts `cpcv == None`, failed CPCV criterion, `promoted == false`.
