# QE-492 — A/B validation harness for the ensemble-objective change: held-out CPCV/DSR gate that must clear before any default flip  *(R5 — panel review 2026-07-31, gates QE-491)*

> **Status:** Todo — [design doc](../../architecture/qe-491-objective-diversification-design.md#4-validation-protocol-the-ship-gate) · [backlog index](../../backlog.md)

`Phase: Review R5 (panel review — PR #182 follow-up)` · `Area: validation / cli / ensemble` · `Depends on / relates to: QE-491 (RiskModel Arm B — the thing under test), QE-469 (CPCV OOS distribution), QE-131/QE-134 (DSR/PBO/CPCV gate); BLOCKS the QE-491 default flip`

**Why.** A change to the *selection* objective (QE-491: retire the correlation penalty, carry diversification through a shrinkage-honest Sharpe) is **unfalsifiable on the in-sample objective value** — that is the exact failure mode the engine's DSR/PBO/CPCV honesty stack exists to prevent. Before `ObjectiveConfig::default` is ever flipped from `RiskModel::RealizedVol` to `ShrunkCorr`, there must be a repeatable experiment proving Arm B beats legacy **on what survives deflation / out-of-sample**, not on what it scores in-sample. Today no such harness exists; QE-491 folds the criterion into prose. This ticket makes the gate a runnable, deterministic artefact so the "accept new selections" decision rests on evidence.

**Scope / requirements.**
- **A/B driver.** A deterministic (QE-006, seeded — no wall-clock/RNG-of-the-day) harness that runs the pipeline twice, Arm A = `RiskModel::RealizedVol` (legacy) and Arm B = `RiskModel::ShrunkCorr`, on identical inputs, and emits a comparison record.
- **Synthetic planted ground truth.** Scale up the fixture generator (`crates/ensemble/src/objective.rs:854-879`): a **high-Sharpe correlated cluster** (ρ≈0.5, per-bar S≈0.15) vs a **zero-Sharpe decorrelated cluster** (ρ≈0, S≈0); assert **B selects the high-Sharpe cluster where A selects the noise cluster**, and run both through `CpcvDistribution::build` — B's lower-percentile held-out DSR clears `CpcvGate.dsr_floor` (`crates/validation/src/cpcv.rs:318`) while A fails. Add a **phantom-decorrelation pool** (low correlations *insignificant* at the fold N) to isolate the Step-1 shrinkage term's value (a δ≡0 variant over-credits it; δ>0 does not).
- **Real Binance walk-forward.** A vs B over `data/lmdb/market` (wiring per `crates/cli/src/jobs/train.rs:801-905`); compare **CPCV `dsr_p05`, PBO (`pbo_cscv`), realized OOS combined Sharpe, and `g1.promoted` rate** across multiple vintages.
- **Pass criterion (the gate).** Emit a machine-checkable verdict: **PASS iff B's CPCV held-out median Sharpe ≥ A AND `dsr_p05` ≥ A AND PBO not worse — on BOTH synthetic and real.** The report is the merge/flip evidence.

**Out of scope.** Implementing the Step-1 objective itself (QE-491) — this harness *tests* it; the Arm-B code can be the Step-0 scaffold until Step 1 lands. Flipping the default (a separate, signed-off decision). Any gate-arithmetic change.

**Acceptance criteria.**
- A deterministic A/B run over the synthetic fixtures produces the planted-ground-truth verdict (B picks edge, A picks noise; B clears `dsr_floor`, A fails), byte-identical across two same-seed runs.
- The real-window A/B produces the four-metric comparison and a single PASS/FAIL against the stated criterion.
- The verdict is recorded as an artefact (not just a log line) a human can attach to the QE-491 default-flip sign-off.
- Runs under the QE-006 harness; no wall-clock / unseeded RNG.
