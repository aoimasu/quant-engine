# QE-494 — Wire the native-tls backend into the `http`-feature fetch agents so real ingest can make HTTPS requests  *(R6 — fleet run 2026-08-01, P0)*

> **Status:** Done (this PR) — [backlog index](../../backlog.md)

`Phase: Review R6 (real-data fleet run)` · `Area: ingest (http feature)` · `Depends on / relates to: QE-101/QE-201 (real REST fetch)`

**Why.** `qe-ingest`'s `ureq` dependency is declared `default-features = false, features = ["native-tls"]` (`crates/ingest/Cargo.toml:43`) — `default-features = false` is deliberate (it drops ring's non-allowlisted OpenSSL licence so `cargo deny` stays green), but it also means **ureq ships no TLS backend unless the agent is built with an explicit `.tls_connector(...)`**. Both agent constructors — `HttpRestSource::new` (`crates/ingest/src/rest.rs:176`) and `HttpFetcher::new` (`crates/ingest/src/fetcher.rs:47`) — built a plain `AgentBuilder` with no connector. Result: **every** `https://` request (all real Binance ingest) fails at runtime with `Unknown Scheme: cannot make HTTPS request because no TLS backend is configured`. The `http` feature had never successfully fetched real data — the fleet run on 2026-08-01 was the first attempt and hit this immediately.

**Scope / requirements.**
- Add `native-tls` as a direct **optional** dep gated on `http` (it is already present transitively via ureq's `native-tls` feature, so `Cargo.lock` gains no new crate and `cargo deny` stays green).
- Wire `.tls_connector(std::sync::Arc::new(native_tls::TlsConnector::new().expect(...)))` into **both** agent constructors. System-TLS init failing is unrecoverable for an https-only client, so `expect` at construction (policy: QE-268 leaves `expect_used` allowed) is the honest stop.

**Out of scope.** Switching TLS backend (rustls) — out of licence scope. Any non-http code path.

**Acceptance criteria.**
- A real `qe ingest --config … --start … --end … --resolution 1h` fetches klines + funding from Binance and writes a real store (verified: BTCUSDT/ETHUSDT 2023-01→2025-06, 21865 bars + 2733 funding each).
- `cargo clippy -p qe-ingest --features http -- -D warnings` clean; `cargo deny check` green (no new crate).

`Spec ref: fleet run 2026-08-01 (high severity — real ingest impossible without it). Touches crates/ingest/{Cargo.toml, src/rest.rs, src/fetcher.rs}.`
