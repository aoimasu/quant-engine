# QE-487 — Model exchange symbol filters (lot/tick/minNotional) at the fill site, OR record an ADR that they are out of scope for the liquid-major universe  *(R5 — panel review 2026-07-31, P2)*

> **Status:** Todo — [panel review](../../reviews/panel-review-2026-07-31.md) · [backlog index](../../backlog.md) · [spec](../../specs.md)

`Phase: Review R5 (panel review)` · `Area: wfo (backtest) / venue` · `Depends on / relates to: existing "NOT tradable-at-size" liquidity screen`

**Why.** The backtester fills are **infinitely divisible at continuous prices** — there is no lot-size (step), tick-size, or `minNotional` anywhere in the fill path. In `crates/wfo/src/backtest.rs` the only quantity guard at the entry fill site is `if qty > Decimal::ZERO` (`backtest.rs:235`, immediately before `apply_fill` at `backtest.rs:240`); the close-side guard is the mirror `if qty > Decimal::ZERO` at `backtest.rs:248` before `apply_fill` at `backtest.rs:254`. `qty` is computed as `notional / price` (`backtest.rs:234`) and passed straight through with no rounding to a step and no rejection below a minimum notional; `price` is the raw bar price with no tick quantization. This lets the simulator hold and trade fractional sizes and hit prices no real venue would fill, overstating realisability. **Verification (genuine but universe-conditional):** the P&L impact is second-order for the deployed liquid-major universe (BTC/ETH-class, where step/tick are tiny relative to sizes) and becomes material only for thin names — so this is a correctness/honesty gap that bites exactly where the current universe does not (yet) trade. It touches the money-math + realisability invariant.

**Scope / requirements.** This is a **HUMAN DECISION** (review §6): model filters *or* ADR-out-of-scope. Implement exactly one branch.
- **Branch A — model the filters.** Add a per-instrument symbol-filter record (`step_size`, `tick_size`, `min_notional`, as exact `rust_decimal::Decimal`). At the fill site, quantize `qty` **down** to a whole multiple of `step_size` (floor toward zero, never round up size), quantize `price` to `tick_size`, and **reject** (skip the fill, as the `qty > ZERO` guard already skips) any order whose post-quantization notional is below `min_notional`. Apply at both fill sites (`backtest.rs:235`/`:240` and `:248`/`:254`) using the same record. Keep all rounding in `Decimal` — no `f64` in the quantization — so fills stay byte-reproducible.
- **Branch B — ADR out of scope.** Write an ADR recording that exchange symbol filters are deliberately out of scope because the deployed universe is liquid-major, where quantization is second-order; AND gate thin-name deployment on the existing **"NOT tradable-at-size"** liquidity screen so any instrument where filters would matter cannot reach deployment unscreened. The ADR must state the re-open trigger (universe expansion to thin names).

**Out of scope.** Slippage/impact/participation modelling (QE-440 ADV machinery stays as-is). Fee/cost math in `apply_fill`. The `qty > Decimal::ZERO` guards themselves (they remain the zero-floor). Under Branch B, **no** change to `backtest.rs` fill math at all. Under Branch A, **no** change to liquid-major backtests unless a real per-instrument filter record is supplied (default/absent filter = today's behaviour, so existing goldens are unaffected).

**Acceptance criteria.**
- **Branch A:** a test that a sub-step `qty` is quantized down to a step multiple and a sub-`minNotional` order is rejected (no fill, no position change); a test that a liquid-major instrument with tiny step/tick produces P&L within tolerance of today's continuous fills. All quantization in `Decimal`; two runs byte-identical (QE-006 harness green). **Branch B:** the ADR file exists and is linked from the backlog; a test/gate assertion proves thin-name deployment is blocked by the "NOT tradable-at-size" screen; `backtest.rs` fill math is unchanged (existing goldens byte-identical).
- Exactly one branch lands; the ticket records which, and the reviewer can confirm the fill path either quantizes or is provably unchanged.
