# QE-491 — Retire the redundant, mis-scaled ensemble correlation penalty; carry diversification through a shrinkage-honest combined Sharpe (A/B gated)  *(R5 — panel review 2026-07-31, follow-up to QE-475, P1)*

> **Status:** Step 0 done (this PR — flag scaffold, default-legacy) · Step 1 Todo — [design doc](../../architecture/qe-491-objective-diversification-design.md) · [panel review](../../reviews/panel-review-2026-07-31.md) · [backlog index](../../backlog.md)

`Phase: Review R5 (panel review — PR #182 follow-up)` · `Area: ensemble (objective) / validation` · `Depends on / relates to: QE-475 (per-unit-risk rescale), QE-430 (deflated corr), QE-469 (CPCV OOS evidence), QE-131/QE-134 (DSR/PBO/CPCV gate); the default flip is GATED BY QE-492 (A/B validation harness)`

**Why.** QE-475 fixed the *magnitude* of the objective's scale mismatch but not its *structure*. The selection objective (`crates/ensemble/src/objective.rs:563`) is `mean/risk + tail_weight·(CVaR/risk) − corr_weight·corr`. The `risk` denominator is the volatility of the **combined** ensemble, and `σ²_combined = Σᵢⱼ wᵢwⱼσᵢσⱼρᵢⱼ` already contains every pairwise ρ — so the `mean/risk` (Sharpe) term **already prices the Markowitz (1952) diversification benefit**, and prices it *correctly* (in proportion to members' own Sharpe). The explicit `− corr_weight·corr` term is therefore a **second, redundant charge for the same property**, on a mis-scaled `∈ [0, 1]` axis with high between-candidate spread that swamps the ~`2·Sharpe ≈ 0.2` return signal at realistic per-bar Sharpe (~0.1). PR#182 finding **R3.1** and the pinned test `decorrelation_still_dominates_at_realistic_low_sharpe` (`objective.rs:~890`) verify a materially higher-mean *correlated* ensemble is still ranked below a near-zero-mean *decorrelated* one. The `CVaR/risk` term is additionally a near-constant shape factor with almost no discriminating power (R3.3), partly double-counting the G1 gate's DSR kurtosis deflation. The one non-redundant job the penalty carried is defending against **phantom in-sample decorrelation** (QE-430) — but dropping the penalty *relocates* that overfit into `σ_combined` (spuriously-low sample corr → spuriously-low vol → spuriously-high Sharpe), so a clean fix must guard it, not just delete it.

**Scope / requirements.**
- **Step 0 (this PR — flag scaffold, default-legacy).** Add `enum RiskModel { RealizedVol, ShrunkCorr }` to `ObjectiveConfig` (`objective.rs`). `RealizedVol` (the default) is byte-identical to the shipped QE-475 objective — every golden and v8 vintage unchanged. `ShrunkCorr` (Arm B, opt-in) retires the explicit `− corr_weight·corr` term; Step-0 keeps the realized-vol denominator (shrinkage δ ≡ 0), so it is a pure retirement of the penalty, ready for A/B. `ObjectiveConfig` has no serde/hash exposure, so the new field cannot move a sealed hash.
- **Step 1 (follow-up — the principled fix).** Under `ShrunkCorr`, replace `risk` with a **Ledoit–Wolf (2004) shrinkage** estimate `sqrt(wᵀ Σ_shrunk w)`, `Σ_shrunk = (1−δ)Σ_sample + δΣ_target`, `Σ_target` = constant-correlation (Elton–Gruber) at `ρ̄`, and `δ = δ(N)` bound to the QE-430 `min_significant_r` significance curve (shrink harder as the fold-slice N shrinks — the honest guard for the *relocated* phantom-decorrelation overfit). Replace the low-discrimination CVaR term with an **excess-tail** `CVaR/risk − ES_gauss(α)` (restores discrimination; de-double-counts the gate). Add a **deflated-correlation admissibility cap** (`max_pairwise_corr > max_corr ⇒ infeasible`, exact-penalty hinge) for the near-duplicate direction the shrinkage denominator does not cover. Re-cast the QE-451 provenance floor (`objective.rs:266`) as a structural admissibility constraint (or provenance-aware shrinkage target) since it currently rides *inside* the penalty.
- **Validation gate (blocks any default flip).** A/B: Arm A = legacy, Arm B = `ShrunkCorr`. Metric is the engine's own honesty stack on **held-out** data — never the in-sample objective value. Datasets: (i) synthetic planted ground truth (high-Sharpe correlated cluster vs zero-Sharpe decorrelated cluster; a phantom-decorrelation pool to isolate the shrinkage term's value); (ii) a real Binance walk-forward. Ship B **only if** its **CPCV held-out median Sharpe ≥ A AND `dsr_p05` ≥ A AND PBO not worse**, on **both**.

**Out of scope.** Any change to the DSR/PBO/CPCV gate arithmetic, the sealed schema, or `VINTAGE_FORMAT_VERSION` (this is a *behaviour* change, not a schema change — a bump would wrongly invalidate v8 artifacts). Scoring the DE search directly on Deflated Sharpe (rejected: with constant `(V,N)` within one search, DSR is a monotone transform of Sharpe ⇒ rank-invariant, so it does not re-rank — keep DSR at the gate).

**Acceptance criteria.**
- **Step 0:** `ObjectiveConfig::with_defaults().risk_model == RealizedVol`; a test proves `ShrunkCorr` equals the legacy objective with the correlation penalty retired *exactly* (`RealizedVol + corr_weight·corr`); the default path is byte-identical (full suite green, no golden moved). **[met in this PR]**
- **Step 1:** the shrinkage denominator + cap + excess-tail land under `ShrunkCorr`; a synthetic test shows B selects the high-Sharpe correlated cluster where A selects the noise cluster, and B's `dsr_p05` clears `CpcvGate.dsr_floor` while A fails; the phantom-decorrelation test shows `ShrunkCorr` (δ>0) does not over-credit insignificant low correlations where the δ≡0 Step-0 variant does; determinism (QE-006) byte-identical across two same-seed runs.
- **Default flip:** only after the validation gate clears, as an explicit signed-off "accept new selections" decision, with both arms sealed in parallel and deltas reported through the QE-469 CPCV surface. No `VINTAGE_FORMAT_VERSION` bump.
